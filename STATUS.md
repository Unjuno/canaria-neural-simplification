# Project status

**2026-08-24:** active experiment execution is paused. The current goal is to make the accumulated research auditable, reusable, and independently reproducible.

The repository should therefore favor:

- frozen historical protocols,
- explicit negative results,
- small reproducible scripts,
- seed-level or cluster-level uncertainty,
- real serialized byte counts where compression is claimed,
- clear separation of confirmatory and exploratory evidence.
