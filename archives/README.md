# Full research snapshot

`canaria_public_research_snapshot.zip` contains the complete curated public snapshot used to initialize this repository: 835 files including 146 Python scripts, 224 Markdown documents, 328 CSV files and 130 JSON files.

SHA256: `2e9930a3d1120f4f36ae1db2817bfcb70f8de5ef60c62351e7bb227117aea5fc`

The snapshot intentionally excludes large derived images, Python caches, and duplicated historical ZIP archives. It includes experiment scripts, experiment reports, locked tables, phase protocols, result summaries, and reproducibility metadata.
