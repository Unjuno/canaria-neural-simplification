## 結論
既視 digits では強い共同学習比較対象に対しても単一写像が有望。選択部分の予算比と全モデル保存量は別で、全体保存差は約1.5%。CPU時間の優位は固定された共有ホスト条件に限定する。
CIFAR の元実験・official test・幅/予算/KL・空間配置・decision-preservation は所定の精度維持条件を満たさなかった。失敗結果を省略しない。
旧 Issue87 の来歴問題は未解決。UCI 外部 writer のデータ取得が成立せず、外部推論・外部確認は未実施。既視 official test を再調整に使わない。

## この版の限界
公開用抜粋は元の完全な実行保存庫ではない。秘密情報・内部運用記録・絶対コンテナパス・モデル本体・画像・外部データを含めない。コードは科学計算部分の参考輸出で、必要なモデルや一部依存コードを同梱しない。変換済みコードを実行済みコードそのものと扱わず、実行可能性・再現性の再検証も主張しない。
JSON は内部運用に関するキーを除去、文書は内部運用行を除去、絶対パスを置換した。原値は原 SHA256 により区別する。監査の合格は仮説成功を意味しない。
過去の decision-preservation メモの526676件は旧記述で、最終監査は528776件。全結果が独立した未見データ確認であるとはしない。
