C = 単一写像の合成置換、L = 局所学習の二写像、J = 共同学習の二写像。以下の比率は、各研究で定義した量に限る。

### 混同しない比較

- **0.5316（旧 C/L）と 0.7883（新 C/J）の差を、比較対象を強化した効果として因果分解しない。** cohort と学習 recipe が異なる。matched-regime は別の、固定2048予算での学習方式の比較である。
- 旧コスト pilot の「bytes と時間をともに5%以上削減」不成立は撤回しない。新研究の教師比削減率とはモデル・比較対象・判定が異なる。
- latency は 30 rounds × 16 seeds × 2 batches × 3 arms = **2,880 timed blocks**、各 block は20 forwards。2,880回だけの forward ではない。最大 block/同セル中央値 25.235倍を含め全記録を保持し、外れ値削除・再試行はしていない。
