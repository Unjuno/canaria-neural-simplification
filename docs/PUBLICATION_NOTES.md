# Publication wording

## Safe opening

> Canaria is a research repository studying task-conditioned simplification of learned neural computations. It provides a reproducible component-wise-versus-composed replacement experiment, explicit protocols and evidence classes, negative results, and correction history.

## Japanese opening

> Canariaは、学習済みニューラル計算をタスクに応じて簡略化できる条件を調べる研究リポジトリです。ブロックごとの近似と合成した入出力関数の近似を比較する再現実験、事前プロトコル、失敗例、訂正履歴を公開しています。

The headline result is limited to the [core digits experiment](CLAIMS_AND_EVIDENCE.md). Newer head-derived correction studies can be mentioned as **separately indexed research**, with their original limitations and review state. Do not advertise “64-to9 model compression”, “minimum dimension predicted”, “universally faster”, “proven LLM compression”, or “independently peer-reviewed” results.

Use [readiness](ANNOUNCEMENT_READINESS.md) and the observed reproduction report before announcing. This file is draft communication guidance, not a posted announcement or a new release.
