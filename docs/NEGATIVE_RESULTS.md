# Negative results and falsified explanations

Negative results are first-class evidence in Canaria. They constrain what the project may claim and prevent successful compression endpoints from being overinterpreted.

## Canary is not a necessary local condition

Strong simplification was frequently observed in low-Canary spans in the blinded confirmatory map. High Canary is therefore not a necessary local condition under the tested sensor definition.

## Canary is not a strong standalone predictor

Adding Canary percentile to width produced only a small LOSO AUC gain and the confidence interval crossed zero. The current Canary signal should be treated as a partial observer of boundary stress/sensitivity, not the root mechanism.

## Implementation boundaries are not always functional boundaries

Individual block replacement can fail while a wider merged span succeeds. Treating implementation blocks as privileged functional atoms is not supported.

## Plain 8-block CNN trainability

The original plain 8-block architecture collapsed to chance-level performance in pilot seeds. Confirmatory work moved to a residual 8-block network before simplification/Canary outcomes were inspected.

## Pure downstream-location explanation

When capacity and adapter class were matched between pre/post boundaries, downstream location itself did not explain the apparent repair advantage.

## Parameter count alone does not explain repair capacity

Equal-parameter interventions did not make repair behavior equivalent. Raw trainable parameter count is therefore an incomplete proxy for task-effective repair dimension.

## Unlimited recursive recompilation

After an initial collapse and repair, a further collapse to extremely small representations generally failed. Current evidence does not support monotonic compilation toward zero complexity.

## Very small scalar-support replacements

Reducing scalar precision was much easier than reducing the number of supported scalar degrees of freedom. Four- or twelve-scalar replacements were insufficient in the tested Conv3 setting.

## Naive two-bit quantization

Naive global/tensor two-bit quantization failed badly. Calibration and channelwise scaling were required for competitive low-precision behavior.

## Unstructured sparsity does not guarantee storage savings

Sparse weights plus explicit indices can exceed the size of a dense low-bit tensor. Structured sparsity was required for a better real storage frontier.

## Some sub-10-KB head designs failed whole-network utility

Several low-rank/structured heads preserved their local transformation yet failed stable whole-network utility. The final 9,926-byte endpoint required a slightly larger, more stable design.

## Teacher-forced PPL does not certify autoregressive equivalence

Across v22–v25, teacher-forced likelihood could remain close to the teacher while free-running greedy trajectories diverged substantially.

## Natural-text post-hoc repair objectives did not close the rollout gap

Under the tested aggressive `4→2` natural-text character-LM setting:

- v23 joint repair did not recover rollout-sensitive fidelity;
- v24 teacher-forced logit KL was insufficient;
- v25 one bounded on-policy trajectory-distillation iteration was insufficient.

These results remain valid even though later training-time consolidation succeeded under a different intervention path.

## Factorized fitting without intervening learning does not explain staged gains

G17 showed that `4→3→2` compiler fitting performed back-to-back, without task learning between stages, was equivalent to direct `4→2` within the preregistered equivalence band. The G15 staged advantage therefore cannot be attributed merely to splitting one fit into two.

## Matched normalized error is not matched task safety

G20e showed that after recontracting, a compiler could reach the same standardized functional-error target with fewer updates yet cause **more** immediate task NLL damage. Easier compiler optimization and downstream robustness are distinct properties.

## Hard task-damage veto can block the target architecture

G21's selective shadow-damage veto failed its target-reach criterion: only 10/12 fresh seeds reached the final two-block model, while mean compiler cost increased.

## One fixed risk cap did not solve the cost/utility trade-off

G27 exploratory tests found that a strict future-risk cap spent more compiler updates for slightly better PPL, while a looser cap saved updates but worsened PPL. No Pareto improvement was established.

## Interpretation rule

A failed local/post-hoc intervention is not evidence that training-time consolidation is impossible. Conversely, a successful training-time toy result is not evidence of universal simplifiability.
