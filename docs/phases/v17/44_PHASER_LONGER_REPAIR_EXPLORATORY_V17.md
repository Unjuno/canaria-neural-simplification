# Phase R — Longer repair follow-up (exploratory)

Designed after Phase Q failed the pre-registered stability criterion. Uses the same fixed representations and same independent seeds 2400–2407; therefore this is exploratory, not confirmatory.

Conditions: 1:4 2-bit with 1, 2, or 8 FP16 scale groups (76, 78, 90 B). Matched continued-training control. Evaluate tau=4 and tau=8 using a single continuous repair trajectory.
