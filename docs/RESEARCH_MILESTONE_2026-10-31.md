# Canaria — 研究の一時凍結・再開条件（2026-10-31）

> **性質：研究終了判断の記録と保存済みスカラー証拠の技術監査。新しいモデル学習・新規seed・未知データ評価・独立査読ではない。** この文書を追加しても、科学的な結果や公開主張の採否は変わらない。

## 0. 何を完了と呼ぶか

約2か月の探索を、**「条件付きの計算置換には実測上の利点があるが、比較対象を強めると追加の全モデル利得は限定的で、別タスクでは品質未達もある」**という、反例を含む一区切りで保存する。全タスクへの一般化・実用製品化・全工程独立再現を完了したとは呼ばない。

この研究フェーズの停止は、無条件の圧縮定理、普遍的な性能利得、正式リリース、広報告知、査読済み論文を意味しない。**止めること自体も有効な研究判断**であり、未解決の仮説をすべて成功させる必要はない。

## 2. 最後に実施する監査の科学的位置付け（H / T / D / C / U）

- **H（反証可能な技術仮説）：** mainに含まれる保存済みスカラー入力から、既存の4種類のsummary（matched/grid/storage/latency）と、25条件の事後感度解析を、元の出力ファイルを読まずに再計算して一致させられる。
- **T（最小検証）：** Ubuntu 24.04、Python 3.11、NumPy 2.3.5。既存の各解析モジュールの全単体テストを実行。4 summaryの保存値を再計算し、しきい値解析を一時ディレクトリへ再生成して**5ファイル**をバイト単位で照合する。25設定のうち20完備・5打切り、元条件のseed方向11/4/1を検査。学習・推論・新規データ・GPU・元の測定は使わない。
- **D（判定）：** 4/4 summary構造と保存値が完全一致、5/5再生成ファイルがbyte一致、25設定の件数・打切りが一致、全単体テストPASSなら **TECHNICAL_SCALAR_RECALC_PASS**。不一致なら **FAIL** として記録し、科学結果を再調整して合わせない。実行環境が用意できない等の未実行は **UNCERTAIN**。
- **C（反証）：** 不一致はソース・依存環境・公開スカラー入力・出力シリアライズの漂流を示す可能性がある。いずれの原因でも確認実験の新規成功にはならない。
- **U（不確かさ）：** この監査は保存済みスカラーを条件とした**決定論的な再計算**で、数値差は厳密一致で判定する。学習データ偏り、再実行時のGPU/CPU差、モデル訓練の変動、選択バイアス、実配備での遅延の不確かさは測定していない。seed-bootstrapの区間はデータセット・ハードウェアを跨ぐ一般化区間ではない。

監査実装：[research-closeout-scalar-audit.yml](../.github/workflows/research-closeout-scalar-audit.yml)。結果のActions run/commitを参照し、実際のrunがPASSするまでは本節の技術ゲートを成功扱いしない。

## 4. 再開トリガーと再開順序

**暫定的に研究をPAUSE**し、プロジェクトを再び開くのは次の条件のいずれかが具体化した場合に限定する。

- 未曝露の独立データセットまたは外部実験者の再現結果を入手し、比較・品質ゲートを事前に固定できる。
- 公開ソースと必要な原入力を完全に束ね、有限の実行条件で**実データ全工程再現**を行う具体的なレビューが通る。
- target hardware・測定条件・必要な**全モデル**利得閾値が先に決まり、比較可能な費用評価を行える。
- CIFARの既存失敗と競合する明確な新機構仮説を提示でき、元official testと独立な選択・確認経路を確保できる。

**再開時の最短順序：** 未解決事項を1つ選択 → fresh protocol / 反証条件・データアクセス・上限をGitに固定 → noninferential preflight → 1回の指定cohort → 生データ/失敗を保存 → 別実装監査 → PASS / FAIL / UNCERTAIN / INVALID を確定し停止。無条件に過去の全研究計画を再起動しない。

## 5. 分野横断の意義

- **機械学習・知識蒸留：** 置換範囲と品質基準を明示し、局所学習L・共同学習J・単一合成Cの因果/容量差を切り分ける。
- **統計・実験計画：** 既視split、事後分析、打切り、seed単位とデータ単位の区別を守る。
- **計算機システム・再現工学：** パラメータ・保存bytes・forward latency・end-to-end資源を別に測る。Git blob証拠保全と実データ完全再現を区別する。

**推奨する次の作業は「休止」であり、追加研究の自動起動ではない。** 完全な文書整理・内部再計算と科学的未解決の誠実な記録ができれば、このフェーズを一区切りとする。
