# Historical index

Legacy versioned protocols/results/scripts, old generalization plans, and past release/review gates are under [archives](../archives/README.md). Their original contents are preserved; old internal links may need the [path map](../publication/PATH_MIGRATION.json).

Use the [whole-project research index](RESEARCH_INDEX.md) for evidence by family and [checkpoint status](../STATUS.md) for the current Digits / CIFAR series. The [eight-seed claim registry](CLAIMS_AND_EVIDENCE.md) and [announcement gate](ANNOUNCEMENT_READINESS.md) concern the historical baseline, not every later result. “Next experiment”, “publication complete”, or “only Issue N remains” inside an archived file describes its historical moment.

The [original review ledger](INDEPENDENT_REREVIEW_2026-08-26.md) is retained as baseline provenance. Neither that ledger nor the frozen snapshot automatically reviews later C-series experiments.


For the current Digits L/J/C and CIFAR series, use the [checkpoint claim registry](../research/public_checkpoint_20261027/docs/claims_checkpoint_20261027/README.ja.md). For the complete family map and later branch evidence, use the [research index](RESEARCH_INDEX.md). Different cohorts and comparison denominators must not be pooled.
